# Changelog

All notable changes to Xius Max Graphics are documented in this file.

## 1.6.7

### Added
- Initial public release for World of Warcraft Forever (TOC `16001`) and modern retail (TOC `120105`).
- Ultimate, Balance, and Defaults presets, plus per-feature MAX / BAL / OFF when you want a custom mix.
- Pick-and-choose world, lighting, effects, and image upgrades past the normal graphics menu.
- Quest loot sparkles, herb and ore glints, and optional quest-object sparkles.
- Movable, resizable options window (`/xmg`) and the same controls under Esc > Options > AddOns.
